# opensim

This folder preserves OpenSim/Moco artifacts from the earlier biomechanics side of the project.

What it is:

- useful context for torque estimation and biomechanics reasoning
- a record of what was explored before the repo leaned harder into RL

What it is not:

- a maintained runnable OpenSim/Moco pipeline inside this cleaned repo

Most contents here are result files, not an actively supported execution stack.
